# Predicting-Seller-Churn-from-Early-Behavioural-Signals-on-an-E-Commerce-Marketplace
Seller churn prediction for a Nigerian e-commerce marketplace. Trained logistic regression, random forest, and XGBoost on 3 years of data from 3,806 sellers to predict 12-month retention using first 60-day signals. Includes survival analysis, SHAP segmentation, plus a playbook and Power BI dashboard.
